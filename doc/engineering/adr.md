# 架构决策记录

## ADR-001：模块化单进程 CLI

2026-10-23，已决定。候选：单文件脚本、分层单进程、服务化。
选择四层单进程：任务是本地编辑器，不存在跨机协作需求；领域与 IO 隔离支撑测试和后续入口。代价是多个小类和装配代码。依赖方向由架构测试验证。

## ADR-002：Command + Composite + 快照

2026-10-23，已决定。候选：逐命令逆操作、完整快照、持久化数据结构。
选择前后快照：跨容器分组、删除子树和绘制顺序必须精确恢复；草稿提交同时实现失败原子性。代价为每次编辑 O(n) 复制和 O(n) 历史空间；不任意截断历史。后续以实际性能报告决定是否有必要改成增量历史，首版先验证 100/1000/10000 元素。

## ADR-003：外部 SVG 导入规范化

2026-10-23，已决定。候选：保留任意 transform、规范化支持子集、只读裸几何。
用户选择常见 SVG 扩展。将 translate、正等比 scale、默认 viewBox 映射展开到画布坐标，解析支持样式继承，保留容器。导入变换需要同步处理字号和线宽；CLI scale 仍严格按附件仅处理几何。旋转/非等比缩放/路径/外部 CSS 明确拒绝，避免未实现特性被保存丢失。

## ADR-004：工程证据与发布

2026-10-23，已决定。使用 Issue/短期分支/PR/CI/分步提交。主分支基线后按阶段合并保留提交，不伪造历史时间或评审。最终验证完成后创建 final，文档以实际 SHA/CI 结果为证据，不声称通过未执行的检查。
